# 🍪 서울 디저트 레이더

서울의 디저트·디저트 팝업 소식을 **매일 12시·24시(KST)** 자동으로 모아 보여주는 사이트.
키워드·가게·지역·디저트 단어는 미리 정한 목록 없이 **수집한 데이터로 자동 결정**되고, 마지막에 **AI(Claude)가 한 번 더 확인**해요.

- 수집: 카카오(다음) 블로그·카페 검색 + 장소 검색 API
- 크롤링: 검색 결과 원문 페이지 (robots.txt 준수)
- AI 2차 확인: Claude API (선택)
- 자동 실행: GitHub Actions (`0 3,15 * * *` UTC = 12:00 / 24:00 KST) · 배포: GitHub Pages

## 구조
```
config/sources.json      시작 단어, 도시·동네, 동작 숫자, 흔한 단어 제외 목록, AI 설정
scripts/collect.mjs      수집 → 판별 → 키워드·가게·지역 → public/data/feed.json
scripts/crawl.mjs        robots.txt를 지키는 원문 크롤러 (사이트별 진단 포함)
scripts/ai.mjs           Claude로 "서울의 디저트 정보인지" 2차 확인
public/index.html        사이트
public/crawl.html        수집·크롤링·AI 점검 페이지
.github/workflows/update.yml   12시·24시 자동 실행 + 배포
```

## 업데이트 한 번에 일어나는 일
1. **1차 검색** — `서울 디저트`(3페이지), 정한 동네(`홍대`·`더현대`·`성수`)의 `○○ 디저트`(2페이지)·`○○ 디저트 팝업`, 지난번 뜬 키워드 `서울 ○○`
2. **크롤링** — 원문 본문·대표 이미지 (robots.txt 차단 사이트는 건너뜀, 1회 최대 150페이지)
3. **디저트 단어장 학습** — "디저트"가 들어간 글 제목의 단어 중, 카카오 장소 검색 결과 절반 이상이 카페·간식 업종인 단어 (버터떡 ✅ / 백화점·패션 ❌). 다음 업데이트로 이어짐
4. **2차 검색 (디저트 발견)** — 발견한 디저트 이름(예: 찹쌀모찌)을 `서울 찹쌀모찌`로 다시 검색 → 🆕 '새로 발견한 디저트'
5. **1차 판별 (규칙)** — "디저트"가 들어간 글 + 제목에 단어장 단어가 있는 글
6. **서울 판별** — 글에 `서울`, 정한 동네, 또는 서울 주소에서 배운 동네 이름(서교·성수·여의도…)이 나오는지
7. **AI 2차 확인** — Claude가 각 글을 읽고 판단
   - 디저트 가게·카페·디저트 팝업·신메뉴·유행 디저트 글인지 (패션·캐릭터 팝업, 일반 식당, 레시피, "말차 염색" 같은 글은 ❌)
   - 위치가 서울인지 (서울 아님 → ❌)
   - 한 번 확인한 글은 저장해 두고 다시 묻지 않음 / AI로 확인된 글만 사이트에 표시(🤖 배지)
8. **뜨는 키워드·가게·지역** — 키워드는 최종 글 제목 기준, 가게는 `서울 ○○` 장소 검색 중 카페·간식 업종 + 서울 주소만. 지역 칩은 ⭐홍대·더현대·성수 + 구

## 시작하기
1. **카카오 REST API 키** — https://developers.kakao.com → 내 애플리케이션 → 앱 키 > REST API 키. 가게 검색이 안 되면 앱 설정에서 **카카오맵** 사용 ON
2. **(선택) Claude API 키** — https://console.anthropic.com → API Keys → Create Key. 사용량만큼 요금이 나와요(작은 모델이라 1회 실행에 보통 몇십 원 수준, 콘솔에서 사용 한도 설정 가능). 키가 없으면 AI 확인 없이 규칙 판별만 해요
3. **GitHub 설정**
   - Settings → Secrets and variables → Actions → `KAKAO_REST_API_KEY`, `ANTHROPIC_API_KEY` 등록
   - Settings → Actions → General → Workflow permissions → **Read and write**
   - Settings → Pages → Source: **GitHub Actions**
4. Actions → "디저트 소식 업데이트 & 배포" → **Run workflow**
5. 결과는 사이트와 `crawl.html`(점검 페이지)에서 확인

## 설정 (`config/sources.json`)
| 항목 | 뜻 |
|---|---|
| `seed` / `city` / `areas` | 시작 단어 / 도시 / 집중할 동네 |
| `seedPages` / `areaPages` | 검색 페이지 수 (페이지당 50건) |
| `expandQueries` / `discoverQueries` | 지난번 키워드·발견한 디저트를 몇 개까지 검색할지 |
| `vocab.*` | 디저트 단어장 학습 기준 |
| `trend.*` | 키워드 기준, 흔한 단어 제외 목록(`stopwords`) |
| `ai.*` | 모델 이름, 한 번에 묻는 글 수, 1회 최대 확인 수 |
| `crawl.*` | 크롤링 속도·양 |
