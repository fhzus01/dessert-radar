# 🍪 디저트 레이더

요즘 뜨는 디저트 소식을 **매일 12시·24시(KST)** 자동으로 모아 보여주는 사이트.
시작 단어 `"디저트"` 하나에서 출발해서 **검색어·키워드·가게·지역이 모두 수집한 데이터로 자동 결정**돼요.

- 수집: 카카오(다음) 블로그·카페 검색 API + 장소 검색 API
- 크롤링: 검색 결과 원문 페이지 (robots.txt 준수)
- 자동 실행: GitHub Actions 크론 (`0 3,15 * * *` UTC = 12:00 / 24:00 KST)
- 배포: GitHub Pages (서버·DB 없이 무료)

## 구조
```
config/sources.json      시작 단어, 동작 숫자, 흔한 단어 제외 목록
scripts/collect.mjs      수집·판별·키워드 추출 → public/data/feed.json
scripts/crawl.mjs        robots.txt를 지키는 원문 크롤러
public/                  정적 사이트 (index.html, app.js, style.css)
.github/workflows/update.yml   12시·24시 자동 수집 + 배포
```

## 업데이트 한 번에 일어나는 일
1. **1차 검색** — `"디저트"`(3페이지) + 지난 업데이트에서 뜬 키워드로 카카오 블로그·카페 검색 (검색어당 최대 50건)
2. **크롤링** — 원문 페이지에서 본문·대표 이미지 (robots.txt 준수, 같은 사이트엔 0.4초 간격, 1회 최대 150페이지)
3. **디저트 단어장 학습**
   - 본문에 "디저트"가 들어간 글의 제목에서 자주 나온 단어를 후보로 뽑고
   - 그 단어로 **카카오 장소 검색**을 해서 결과의 절반 이상이 카페·간식 가게면 디저트 단어로 인정
     (버터떡·말차 → 카페/제과점이 나옴 ✅ / 백화점·지역·패션 → 다른 업종이 많이 나옴 ❌)
   - 배운 단어는 다음 업데이트로 이어져서 단어장이 계속 커짐
4. **디저트 글 판별** — "디저트"가 들어간 글 + 제목에 단어장 단어가 있는 글
   → "버터떡 웨이팅 2시간"처럼 '디저트'란 말이 없어도 디저트 글로 잡혀요
5. **2차 검색 (디저트 발견)** — "디저트" 검색 결과에서 발견한 디저트 이름(예: 찹쌀모찌, 모찌떡)을 **하나씩 다시 검색**해서 그 디저트 글도 보여줘요. 처음 발견한 단어부터 최대 20개(`discoverQueries`). 사이트의 🆕 '이번에 새로 발견한 디저트'에 표시
6. **지금 뜨는 키워드** — 디저트 글 제목에서 많이 나온 단어장 단어 (3개 이상 글, 2명 이상 작성자)
7. **가게·지역** — 뜨는 키워드의 장소 검색 결과 중 카페·간식 업종. 가게 주소로 지역 목록 자동 생성·누적
8. **많이 올린 작성자** 집계

> 한계: "말차 염색"처럼 디저트 단어가 다른 뜻으로 쓰인 글이 가끔 섞일 수 있어요.

## 시작하기
1. **카카오 REST API 키** — https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가하기 → **앱 키 > REST API 키** 복사. 가게 검색이 안 되면 앱 설정에서 **카카오맵** 사용 설정 ON
2. **GitHub 설정**
   - Settings → Secrets and variables → Actions → `KAKAO_REST_API_KEY` 등록
   - Settings → Actions → General → Workflow permissions → **Read and write**
   - Settings → Pages → Source: **GitHub Actions**
3. Actions 탭 → "디저트 소식 업데이트 & 배포" → **Run workflow**
4. 로컬 실행: `KAKAO_REST_API_KEY=xxx node scripts/collect.mjs` 후 `npx serve public`

> 첫 업데이트부터 2차 검색까지 하지만, 몇 번 돌수록 단어장·가게·지역이 더 쌓여요.

## 설정 (`config/sources.json`)
| 항목 | 뜻 |
|---|---|
| `seed` | 시작 단어 (사이트 주제) |
| `expandQueries` | 지난번 뜬 키워드 중 몇 개를 다음 검색어로 쓸지 |
| `discoverQueries` | 발견한 디저트 이름을 몇 개까지 추가 검색할지 |
| `keepDays` | 며칠 지난 글까지 보여줄지 |
| `seedPages` | "디저트" 검색 페이지 수 (페이지당 50건) |
| `vocab.*` | 디저트 단어장 학습 기준 |
| `trend.minPosts / minSources` | 키워드 기준 |
| `trend.stopwords` | "후기", "맛집" 같은 흔한 단어 — 엉뚱한 단어가 순위에 끼면 여기 추가 |
| `crawl.*` | 크롤링 속도·양 |
